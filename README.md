# Shopify reference component showcase

A Vite + React + TypeScript component study based on manual desktop inspection of two Shopify storefront patterns. It contains original copy and CSS placeholder art only.

## Run locally

```sh
pnpm install
pnpm dev
```

## Verify

```sh
pnpm test
pnpm build
```

## GitHub Pages

The Pages workflow builds on pushes to `main`. Vite derives the repository base path from GitHub's `GITHUB_REPOSITORY` environment variable, so both user sites and project sites are supported without a hard-coded repository name. Enable **GitHub Actions** as the Pages source in repository settings.
